# typsmthng website

Product showcase for [typsmthng](https://typsmthng.coolstuff.work).

## Related projects

- [typsmthng](../typsmthng) // web editor
- [typsmthng-desktop](../typsmthng-desktop) // desktop editor

## Stack

Astro, React, Tailwind CSS 4, Motion, shadcn/ui

## Structure

```
apps/web/          # Astro site
  src/
    components/    # React components
    layouts/
    pages/
  public/
    screenshots/
packages/ui/       # Shared UI + design tokens
```

## Development

```bash
bun install
bun run dev
```

## Build

```bash
bun run build
```
